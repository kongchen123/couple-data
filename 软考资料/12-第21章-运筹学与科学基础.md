## 二、六大题型与解法

### 21.1 线性规划（Linear Programming）

**特征**：求"在一定约束下，使目标最大/最小"。

**标准解法：图解法（二维）**

```
① 设决策变量 x、y
② 列出目标函数（max z = ax + by）
③ 列出约束条件（不等式组 + 非负约束）
④ 在坐标系画出各约束直线，确定可行域
⑤ 求可行域各顶点坐标（联立方程）
⑥ 代入目标函数，比较大小，取最优
```

**核心定理**
> **最优解一定在可行域的顶点（角点）上取得。** 所以只需比较各顶点的目标函数值。

**例题**
```
某厂生产 A、B 两种产品，A 每件利润 40 元，B 每件 30 元。
资源约束：
  原料：2x + y ≤ 100
  工时：x + 2y ≤ 80
  非负：x, y ≥ 0
求最大利润。

解：可行域顶点为
  (0,0)、 (50,0)、 (40,20)、 (0,40)
  z = 40x + 30y 代入：
  (0,0):   0
  (50,0):  2000
  (40,20): 40×40 + 30×20 = 2200  ← 最大
  (0,40):  1200
答：生产 A 40 件、B 20 件，最大利润 2200 元。
```

### 21.2 决策论（Decision Theory）

**特征**：在**不确定环境**下选择方案。给出各方案在不同自然状态下的收益。

**四种决策准则（必背）**

| 准则 | 思路 | 计算 | 决策者类型 |
|---|---|---|---|
| **乐观准则（Max-Max）** | 选"最好情况中最好的" | 每个方案取**最大值**，再取最大 | 冒险型 |
| **悲观准则（Max-Min）** | 选"最坏情况中最好的" | 每个方案取**最小值**，再取最大 | 保守型 |
| **等可能准则（Laplace）** | 认为各状态概率相等 | 每方案**求平均**，取最大 | 中庸型 |
| **后悔值准则（Min-Max Regret）** | 选"后悔最小的" | 算后悔值矩阵，每方案取**最大后悔**，再取最小 | 稳健型 |

**后悔值计算**
```
某列的最大值 − 该列各值 = 后悔值（机会损失）
```

**例题**
```
         状态1   状态2   状态3
方案A      50      40      20
方案B      70      30      10
方案C      40      35      30

乐观：A=50, B=70, C=40 → 选 B（70）
悲观：A=20, B=10, C=30 → 选 C（30）
等可能：A=36.7, B=36.7, C=35 → 选 A 或 B
后悔值：
  状态1最大值=70 → 后悔 A=20, B=0, C=30
  状态2最大值=40 → 后悔 A=0, B=10, C=5
  状态3最大值=30 → 后悔 A=10, B=20, C=0
  各方案最大后悔：A=20, B=20, C=30 → 选 A 或 B（20）
```

> 注意：**乐观和悲观都是"先取极值再选"，但取的方向相反**。乐观取每行最大，悲观取每行最小。

### 21.3 博弈论（Game Theory）

**特征**：双方决策相互影响，一方所得即另一方所失（**零和博弈**）。

**核心解法：矩阵博弈的"最大最小"原则**

```
对收益矩阵（甲方收益）：
  ① 每行取最小值 → 取其中最大值 = 甲方的最优策略（maximin）
  ② 每列取最大值 → 取其中最小值 = 乙方的最优策略（minimax）
  ③ 若两个值相等（存在鞍点），则为纯策略纳什均衡
```

**例题**
```
        乙1    乙2    乙3
甲1      6      5      8
甲2      4      7      3
甲3      2      6      9

甲（行）取每行最小：6, 3, 2 → 取最大 = 6（选甲1）
乙（列）取每列最大：6, 7, 9 → 取最小 = 6（选乙1）
两者都是 6，存在鞍点 → 均衡策略为（甲1, 乙1），博弈值 6
```

**关键概念**
- **鞍点**：行最小与列最大相等的位置，对应纯策略均衡
- **混合策略**：不存在鞍点时，需按概率随机选择（本题型一般考到鞍点为止）

### 21.4 排队论（Queuing Theory）

**特征**：计算服务系统的效率指标。高项常考 **M/M/1** 模型（单服务台）。

**核心公式（必背）**

```
λ = 平均到达率（单位时间到达数）
μ = 平均服务率（单位时间可服务数）
ρ = λ / μ  （服务强度/利用率，必须 < 1）

平均队长（系统内顾客数）：  Ls = λ / (μ − λ)
平均队列长（等待的顾客数）：Lq = λ² / (μ(μ − λ)) = Ls × ρ
平均逗留时间（含服务）：    Ws = 1 / (μ − λ)
平均等待时间：              Wq = λ / (μ(μ − λ)) = Ws × ρ
空闲概率：                  P0 = 1 − ρ
```

> 记忆：**Ls = λ/(μ−λ)**，**Ws = 1/(μ−λ)**，其余都是这两个乘 ρ。

**例题**
```
银行 1 个窗口，顾客平均每小时到 12 人（λ=12），
每笔业务平均 4 分钟（μ=15 人/小时）。
求：平均排队人数、平均等待时间。

ρ = 12/15 = 0.8
Ls = 12/(15−12) = 4 人
Lq = 4 × 0.8 = 3.2 人（平均 3.2 人在排队）
Ws = 1/(15−12) = 1/3 小时 = 20 分钟
Wq = 20 × 0.8 = 16 分钟（平均等待 16 分钟）
```

### 21.5 网络计划（PERT / CPM 概率计算）

**特征**：与进度管理的关键路径结合，考**完工概率**。

**核心公式**

```
活动工期期望：te = (O + 4M + P) / 6
活动工期方差：σ² = ((P − O) / 6)²

项目工期期望 = 关键路径上各活动 te 之和
项目总方差   = 关键路径上各活动方差之和（注意：只加关键路径上的）

标准差 σ = √(总方差)

完工概率：Z = (要求工期 T − 期望工期 TE) / σ
查标准正态分布表得概率
```

**常用正态分布值（必背）**

| Z | 概率 |
|---|---|
| 0 | 50% |
| 1 | **84.13%** |
| 1.28 | 90% |
| 1.645 | **95%** |
| 1.96 | 97.5% |
| 2 | 97.72% |
| 3 | 99.87% |

**例题**
```
关键路径 A→B→C，te 分别为 10、8、12 天，方差分别为 1、4、9。
项目要求 35 天内完工，求概率。

TE = 10+8+12 = 30 天
总方差 = 1+4+9 = 14
σ = √14 ≈ 3.74
Z = (35 − 30) / 3.74 = 1.34
查表：Z=1.34 → 概率约 91%

答：35 天内完工概率约 91%。
```

> 注意：**只累加关键路径上的方差**，非关键活动不计入。

### 21.6 最小生成树与最短路径

**最小生成树**：连接所有节点且**总权重最小**（不留回路）——用于网络布线、管道铺设。

**Prim 算法 / Kruskal 算法**
- **Kruskal（避圈法）**：每次选**权重最小且不成环**的边，直到连完所有点
- **Prim（加点法）**：从一个点出发，每次选与已选集合连接的**最小边**

**最短路径**：从起点到终点的最短距离——常用 **Dijkstra 算法**。

**Dijkstra 步骤**
```
① 起点标 0，其余标 ∞
② 每次从"未确定的点"中选距离最小的点，确定其最短距离
③ 用该点更新邻居的距离
④ 重复直到终点确定
```

**考试技巧**
> 节点不多（5~8 个）时，直接**枚举所有路径求和比较**往往比套算法更快，且不易出错。

## 三、高频易错对照表

| # | 陷阱 | 正解 |
|---|---|---|
| 1 | 线性规划最优解在可行域内部 | 一定在**顶点（角点）**上 |
| 2 | 乐观准则是取每行最小值 | 乐观取**最大值**（Max-Max）；悲观才取最小（Max-Min） |
| 3 | 后悔值直接用收益值 | 后悔值 = **该列最大值 − 该值** |
| 4 | 博弈论中双方取同一个方向 | 甲取**行最小中的最大**，乙取**列最大中的最小** |
| 5 | 排队论 ρ 可以大于 1 | **ρ = λ/μ 必须 < 1**，否则队列无限增长 |
| 6 | 项目总方差包含所有活动 | 只累加**关键路径**上的活动方差 |
| 7 | Z 值为正表示概率小于 50% | Z>0 表示概率**大于** 50% |
| 8 | 最小生成树允许成环 | 绝不能成环，否则是"图"不是"树" |
| 9 | 等可能准则给各状态不同概率 | 等可能即**概率相等**（1/n） |
| 10 | 排队论 Ws 是等待时间 | Ws 是**逗留时间**（含服务），Wq 才是等待时间 |
