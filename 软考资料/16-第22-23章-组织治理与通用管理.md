## 二、第22章 组织通用治理

### 22.1 组织治理

**定义**：组织治理是**董事会/最高管理层**通过制度安排，确保组织**目标实现、风险可控、责任明确**的机制。

**治理的四个核心**
```
① 战略方向（定方向）
② 监督执行（看执行）
③ 问责机制（有问责）
④ 信息披露（透明度）
```

**治理与管理的区别**

| | 治理 | 管理 |
|---|---|---|
| 层级 | 董事会/高层 | 经营层 |
| 关注 | **做不做、方向对不对** | **怎么做、效率高不高** |
| 手段 | 制度、监督、问责 | 计划、组织、控制 |

### 22.2 组织战略管理

**战略管理的过程（必背）**
```
① 战略分析（环境分析：SWOT、PEST）
② 战略制定（使命、愿景、目标、策略）
③ 战略实施（资源配置、组织调整）
④ 战略评价与控制（评估、纠偏）
```

**PEST 分析（宏观环境）**

| 维度 | 内容 |
|---|---|
| **P**olitical 政治 | 政策、法规、政治稳定性 |
| **E**conomic 经济 | 经济增长、利率、通胀 |
| **S**ocial 社会 | 人口、文化、消费习惯 |
| **T**echnological 技术 | 技术趋势、创新 |

**SWOT 分析**

| | 有利 | 不利 |
|---|---|---|
| **内部** | **S**trengths 优势 | **W**eaknesses 劣势 |
| **外部** | **O**pportunities 机会 | **T**hreats 威胁 |

> 战略组合：**SO**（增长型，用优势抓机会）、**WO**（扭转型，补劣势抓机会）、**ST**（多种经营，用优势避威胁）、**WT**（防御型，补劣势避威胁）。

### 22.3 组织级项目管理与战略对齐

**核心逻辑**
```
组织战略 → 项目组合（选项目）→ 项目集/项目（做项目）→ 交付价值 → 反哺战略
```

**关键论断**：**项目的价值必须放在组织战略的框架下衡量**——一个按时按预算交付但与战略无关的项目，对组织是浪费。

### 22.4 组织变革管理

**变革的阻力来源**
- 个人层面：习惯、安全感、利益受损、认知不足
- 组织层面：结构惯性、文化、资源约束、权力格局

**变革管理的关键**
- 高层支持（最重要）
- 充分沟通（说明"为什么变"）
- 参与决策（让干系人参与）
- 培训与支持
- 循序渐进、及时激励

**科特（Kotter）变革八步（了解即可）**
```
① 建立紧迫感 ② 组建领导联盟 ③ 形成愿景战略
④ 沟通变革愿景 ⑤ 授权行动 ⑥ 创造短期胜利
⑦ 巩固成果再推进 ⑧ 固化到文化中
```

## 三、第23章 组织通用管理

### 23.1 流程管理

**流程的三要素**
```
输入 → 活动（增值） → 输出
```

**流程管理的核心**
- 识别**核心流程**（直接创造价值的）
- 识别**支持流程**（辅助性的）
- 流程**优化**（消除不增值环节）

**流程优化的方法**
- **ESIA**：**E**liminate 消除、**S**implify 简化、**I**ntegrate 整合、**A**utomate 自动化
- **BPR**（业务流程重组）：**根本性、彻底性**的重新设计（不是渐进改进）

> 区分：**流程优化是渐进的改良**，**BPR 是彻底的再造**。BPR 风险高、失败率高。

### 23.2 知识管理

**知识的两类（必考）**

| 类型 | 含义 | 特点 |
|---|---|---|
| **显性知识**（Explicit） | 可编码、可文档化 | 易传递、易存储（文档、手册、数据库） |
| **隐性知识**（Tacit） | 难以言传、藏在个人经验中 | 难传递（经验、直觉、诀窍） |

**知识转化的 SECI 模型（必考）**

```
① 社会化（Socialization）    隐性 → 隐性   （师徒、观察学习）
② 外化（Externalization）    隐性 → 显性   （写下来、比喻、模型）
③ 组合化（Combination）      显性 → 显性   （整理、归类、整合）
④ 内化（Internalization）    显性 → 隐性   （学习、实践、吸收）
```

> 记忆：**社外组内**（社会化、外化、组合化、内化）。
> 最难的转化是**隐性→显性（外化）**，因为隐性知识难以表达。

**知识管理的落地**
- 建立知识库（显性知识沉淀）
- 导师制/结对（隐性知识传递）
- 经验教训登记册（项目收尾必做）

### 23.3 人力资源管理（通用管理视角）

**人力资源管理的四大模块**
```
① 人力资源规划（要多少人、什么能力）
② 招聘与配置（招人、分配）
③ 培训与开发（提升能力）
④ 绩效与薪酬（评价、激励）
```

**绩效管理的循环**
```
目标设定 → 过程辅导 → 绩效考核 → 结果应用（奖惩/发展）
```

> 关键论断：**绩效管理不只是"考核"，更重要的是"过程辅导"和"结果应用"**。

### 23.4 财务管理基础

**三张核心报表**

| 报表 | 反映什么 |
|---|---|
| **资产负债表** | 某一时点的**财务状况**（资产 = 负债 + 所有者权益） |
| **利润表**（损益表） | 一段期间的**经营成果**（收入 − 成本费用 = 利润） |
| **现金流量表** | 一段期间的**现金流入流出** |

> 记忆：**资产负债表看"家底"（时点），利润表看"赚没赚"（期间），现金流量表看"有没有钱"（期间）。**

**财务分析的关键指标**
```
投资回收期（Payback Period）—— 多久收回投资
ROI（投资回报率）= 收益 / 投资额
NPV（净现值）—— 未来现金流折现后减去投资，>0 才可行
IRR（内部收益率）—— NPV = 0 时的折现率
```

> 项目决策中：**NPV > 0 项目可行**；**投资回收期越短越好**；**IRR 越高越好**。

### 23.5 供应链与采购（通用视角）

**供应链的核心**
```
供应商 → 制造商 → 分销商 → 零售商 → 客户
```

**关键概念**
- **JIT（准时制）**：零库存，按需交付
- **VMI（供应商管理库存）**：供应商负责管理客户库存
- **牛鞭效应**：需求信息在供应链上逐级放大，导致库存波动

> **牛鞭效应**是高频考点：需求沿供应链向上游传递时被**逐级放大**。

### 23.6 战略人力资源与组织能力

**组织能力的三角（杨国安）**
- **员工能力**（会不会）
- **员工思维**（愿不愿）
- **员工治理**（容不容许）

## 四、高频易错对照表

| # | 陷阱 | 正解 |
|---|---|---|
| 1 | 治理就是管理 | 治理管方向与问责，管理管执行与效率 |
| 2 | BPR 是渐进改进 | BPR 是**根本性、彻底性**再造；渐进的是流程优化 |
| 3 | 隐性知识容易传递 | 隐性知识**难以言传**，最难转化 |
| 4 | SECI 中"外化"是显性到显性 | 外化是**隐性→显性**；显性→显性是组合化 |
| 5 | 资产负债表反映一段期间 | 反映**某一时点**的财务状况 |
| 6 | 利润表看现金流 | 利润表看**经营成果**；现金流量表看现金进出 |
| 7 | NPV < 0 项目可行 | **NPV > 0** 才可行 |
| 8 | 投资回收期越长越好 | **越短越好** |
| 9 | 牛鞭效应说明需求稳定 | 说明需求信息被**逐级放大** |
| 10 | 绩效管理就是考核 | 还包括**过程辅导与结果应用** |
| 11 | SWOT 中 O 是内部因素 | O（机会）和 T（威胁）都是**外部**因素 |
| 12 | SECI 中社会化是显性到显性 | 社会化是**隐性→隐性**（师徒、观察） |
| 13 | PEST 的 S 是战略 | S 是**社会**（Social） |
| 14 | 变革阻力主要来自技术 | 主要来自**人**（习惯、利益、认知） |

## 五、案例题应用

**这两章在案例中的常见考法**
- "从组织治理角度分析项目失败原因"
- "项目知识未能沉淀，属于哪类知识管理问题"

**作答要点**
```
知识管理角度：
1. 项目未建立经验教训登记册，隐性知识未显性化
2. 未开展知识分享活动（导师制、评审、复盘）
3. 未建立知识库，显性知识无法检索复用
4. 人员流动导致隐性知识流失

流程管理角度：
1. 核心流程未识别，资源投在非增值环节
2. 流程未优化，审批环节冗余
3. 缺乏流程绩效度量
```

## 六、论文要点

**可能用到的素材**
- **知识管理的实践**：建立项目知识库 + 每周技术分享 + 收尾复盘，隐性知识显性化
- **流程优化**：用 ESIA 优化需求评审流程，从 5 天缩短到 2 天
- **组织变革**：推动敏捷转型时如何应对阻力（高层支持 + 试点 + 短期胜利）
- **战略对齐**：如何论证项目与组织战略的一致性
