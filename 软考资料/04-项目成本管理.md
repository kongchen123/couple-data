# 项目成本管理 · 重点知识点

> 第4版教材第11章 · 4 个过程 · 综合知识 4~6 分 · **计算题必考（挣值分析）**

---

## 一、定位：挣值分析是本领域全部考点

**核心定义**：成本管理是规划、估算、预算、融资、筹措资金、管理并控制成本，使项目在**批准的预算内完成**的过程。

**四个过程与过程组分布**

```
规划 ─── 规划成本管理、估算成本、制定预算
监控 ─── 控制成本
```

**成本管理的核心链条**

```
定规则 → 估成本 → 汇预算（形成成本基准）→ 控成本（挣值分析）
```

**三种成本概念（易混）**

| 概念 | 英文 | 含义 |
|---|---|---|
| **全生命周期成本** | LCC | 从**获取到处置**的总成本（含运维） |
| **应急储备** | Contingency Reserve | 应对**已识别**风险，**在成本基准内** |
| **管理储备** | Management Reserve | 应对**未识别**风险，**不在成本基准内** |

> **项目预算 = 成本基准 + 管理储备**

## 二、四个过程总表

| 过程 | 过程组 | 关键输入 | 关键工具 | 关键输出 |
|---|---|---|---|---|
| **规划成本管理** | 规划 | 项目章程、项目管理计划、EEF、OPA | 专家判断、数据分析、会议 | **成本管理计划** |
| **估算成本** | 规划 | 项目管理计划、项目文件、EEF、OPA | **类比估算、参数估算、自下而上估算、三点估算**、储备分析、质量成本、**决策**、**数据分析**、**项目管理信息系统** | **成本估算**、估算依据、项目文件更新 |
| **制定预算** | 规划 | 项目管理计划、**可行性研究文件**、项目文件、协议、EEF、OPA | **专家判断、成本汇总、储备分析、历史信息审核、资金限制平衡、融资** | **成本基准**、项目资金需求、项目文件更新 |
| **控制成本** | 监控 | 项目管理计划、项目文件、**工作绩效数据**、OPA | **挣值分析、偏差分析、趋势分析**、完工尚需绩效指数、**储备分析** | 工作绩效信息、**成本预测**、变更请求 |

**两条容易记错的点**
1. "制定预算" 的输出是**成本基准**，估算成本只输出**成本估算**
2. "控制成本" 输出**成本预测**（EAC/ETC），不是成本基准

## 三、逐个重点

### 11.2 规划成本管理

**成本管理计划内容**：计量单位、精确度、准确度、组织程序链接、**控制临界值**、**绩效测量规则（EVM 规则）**、报告格式、过程描述、其他细节。

> **控制临界值**：规定偏差达到多少百分比必须采取行动（如 ±10% 以内不干预）。

---

### 11.3 估算成本

**四种估算法（与进度管理同源）**

| 方法 | 原理 | 准确度 | 适用阶段 |
|---|---|---|---|
| **类比估算** | 参考类似项目 | 低（−25%~+75%） | 早期 |
| **参数估算** | 参数模型（如每行代码成本 × 行数） | 中（−15%~+25%） | 有历史数据 |
| **自下而上估算** | 逐层汇总 | 高（−5%~+10%） | 详细阶段 |
| **三点估算** | 考虑不确定性 | 高 | 不确定性大 |

**质量成本（COQ）—— 估算成本的特殊考虑**

| 类别 | 内容 |
|---|---|
| **一致性成本**（预防失败） | **预防成本**（培训、设计审查）、**评估成本**（测试、检查） |
| **非一致性成本**（失败后处理） | **内部失败成本**（返工、报废）、**外部失败成本**（保修、召回、索赔） |

> 口诀：**预防最便宜，外部失败最贵。** 投入在预防和评估上的钱，是为了减少返工与索赔。

---

### 11.4 制定预算（形成成本基准）

**成本基准的结构**

```
项目预算
├── 管理储备（应对未识别风险，高层管理，不在基准内）
└── 成本基准（用于挣值分析）
    ├── 应急储备（应对已识别风险，PM 管理）
    └── 各工作包成本 + 活动应急储备
        └── 按时间段累积 → S 曲线
```

**两个关键概念**

| 概念 | 含义 |
|---|---|
| **成本基准** | 经过批准的、按时间段分配的项目预算，**不含管理储备**，是挣值分析的基准 |
| **项目资金需求** | 总需求 = 成本基准 + 管理储备，通常是**阶梯式递增** |

**资金限制平衡**：把资金投入与组织的资金限制做平衡，可能要调整活动时间（**注意：这会改变成本基线的时间分布**）。

---

### 11.5 控制成本（挣值分析 —— 全书最重要的计算）

**三个基础指标（必背）**

| 指标 | 全称 | 定义 | 含义 |
|---|---|---|---|
| **PV** | Planned Value（计划值） | 计划完成工作的**预算价值** | 计划到某时点应该完成多少活（按预算算） |
| **EV** | Earned Value（挣值） | **实际完成**工作的**预算价值** | 实际完成了多少活（按预算算） |
| **AC** | Actual Cost（实际成本） | 实际完成工作所**实际花费** | 实际花了多少钱 |

> **记忆要点：EV 永远在"上面"**（公式里 EV 是分子/被减数）。PV 和 AC 都表示"应该/实际花费"，只有 EV 表示"挣到了多少"。

**四个偏差/绩效指标（必背）**

| 指标 | 公式 | 含义 | 判断 |
|---|---|---|---|
| **SV**（进度偏差） | SV = EV − PV | 进度偏差（**成本单位**） | >0 提前，<0 落后 |
| **CV**（成本偏差） | CV = EV − AC | 成本偏差 | >0 节约，<0 超支 |
| **SPI**（进度绩效指数） | SPI = EV / PV | 进度效率 | >1 提前，<1 落后 |
| **CPI**（成本绩效指数） | CPI = EV / AC | 成本效率 | >1 节约，<1 超支 |

> **口诀：SV/CV 是减法，看正负；SPI/CPI 是除法，看与 1 比较。**

**完工估算（EAC）—— 三种情形（必考辨析）**

| 情形 | 判断依据 | 公式 |
|---|---|---|
| **典型偏差**（偏差会持续） | 剩余工作**仍按当前 CPI** 进行 | **EAC = BAC / CPI** |
| **非典型偏差**（偏差不再发生） | 剩余工作**按原计划预算**进行 | **EAC = AC + (BAC − EV)** |
| 同时考虑进度与成本 | 需要赶工 | **EAC = AC + (BAC − EV) / (CPI × SPI)** |

> **判断口诀**：题干出现"**照此趋势继续**""**剩余工作仍按当前绩效**"→ 典型（`BAC/CPI`）；出现"**剩余工作按计划预算完成**""**偏差是偶然的**"→ 非典型（`AC + BAC − EV`）。

**其他衍生公式**

```
ETC（完工尚需估算）
  典型：  ETC = (BAC − EV) / CPI
  非典型：ETC = BAC − EV
  （EAC = AC + ETC，两种情形都成立）

VAC（完工偏差）= BAC − EAC
  >0 预计节约，<0 预计超支

TCPI（完工尚需绩效指数）
  按原预算完成：  TCPI = (BAC − EV) / (BAC − AC)
  按 EAC 完成：   TCPI = (BAC − EV) / (EAC − AC)
  >1 表示剩余工作必须比计划更有效率
```

**完整计算例题**

```
某项目 BAC = 100 万，当前时点：
  PV = 40 万，EV = 30 万，AC = 35 万

求：SV、CV、SPI、CPI，判断进度与成本状况；
    若偏差为典型，求 EAC、ETC、VAC。

解：
  SV = EV − PV = 30 − 40 = −10 万   → 进度落后 10 万
  CV = EV − AC = 30 − 35 = −5 万    → 成本超支 5 万
  SPI = EV / PV = 30 / 40 = 0.75    → 进度落后（完成 75% 的计划工作量）
  CPI = EV / AC = 30 / 35 = 0.857   → 成本超支（每花 1 元只挣到 0.857 元）

  EAC = BAC / CPI = 100 / 0.857 = 116.7 万
  ETC = EAC − AC = 116.7 − 35 = 81.7 万
  VAC = BAC − EAC = 100 − 116.7 = −16.7 万（预计超支）

结论：项目进度落后、成本超支，按当前趋势完工预计需 116.7 万，超支 16.7 万。
```

**偏差的四种组合及应对**

| 组合 | 含义 | 应对 |
|---|---|---|
| SV>0, CV>0 | 提前且节约 | 保持，注意质量 |
| SV>0, CV<0 | 提前但超支 | 控制成本，检查是否靠加班/堆人 |
| SV<0, CV>0 | 落后但节约 | 可考虑适当增加投入赶进度 |
| SV<0, CV<0 | 落后且超支 | **最严重**，需立即干预 + 变更 |

**控制成本的输出：成本预测**——基于当前绩效推算的 EAC/ETC，是"预测"而非"实际"。

## 四、高频易错对照表

| # | 陷阱 | 正解 |
|---|---|---|
| 1 | EV 是实际花费 | EV 是**挣值**（实际完成工作的预算价值）；**AC 才是实际花费** |
| 2 | PV 是已完成工作的价值 | PV 是**计划**完成工作的预算价值 |
| 3 | CV = EV − PV | CV = **EV − AC**（成本）；EV − PV 是 SV |
| 4 | CPI < 1 表示进度落后 | CPI < 1 表示**成本超支**；SPI < 1 才是进度落后 |
| 5 | 典型偏差用 BAC − EV | 典型用 **BAC / CPI**；非典型才用 AC + (BAC − EV) |
| 6 | 管理储备包含在成本基准内 | **不包含**，项目预算 = 成本基准 + 管理储备 |
| 7 | 成本基准包含管理储备 | 只包含**应急储备** |
| 8 | 应急储备由高层管理 | 由 **PM** 管理；管理储备由高层管理 |
| 9 | 制定预算输出成本估算 | 输出**成本基准**与项目资金需求 |
| 10 | 控制成本输出成本基准 | 输出**成本预测** |
| 11 | 外部失败成本比预防成本低 | **外部失败最贵**（保修、索赔、声誉） |
| 12 | 三点估算除以 3 | PERT 默认 **除以 6** |
| 13 | VAC > 0 表示超支 | VAC = BAC − EAC，**>0 表示节约** |
| 14 | 成本估算准确度自下而上最低 | **自下而上最高**（−5%~+10%） |

**成本超支类案例的常见问题与措施**

```
问题：
1. 成本估算方法不当，未考虑风险与应急储备
2. 未建立成本基准，或无成本控制流程
3. 未定期进行挣值分析，偏差发现滞后
4. 范围蔓延导致成本超支（未走变更流程）
5. 资源使用效率低，返工率高（质量成本上升）
6. 成本超支后未分析原因即压缩其他活动

措施：
1. 采用自下而上估算提高准确度，合理设置应急与管理储备
2. 制定成本基准并获批准，建立成本控制流程
3. 定期（如每月）做挣值分析，SPI/CPI 低于临界值即预警
4. 严格变更控制，所有范围变更评估成本影响
5. 加强质量管理，降低内部/外部失败成本
6. 超支时分析根本原因，采取纠正措施并更新成本预测
```

**结构**：背景 300 字 → 过程论述 1500 字 → 问题与解决 400 字 → 总结 200 字

5. ETC、VAC、TCPI 的公式？
6. 成本基准包含管理储备吗？项目预算等于什么？
7. 应急储备与管理储备的区别？
8. 一致性成本与非一致性成本的四个子类？
9. 自下而上估算的准确度区间？

<details>
<summary>答案</summary>

1. 规划 3 个（规划成本管理、估算成本、制定预算），监控 1 个（控制成本）。
2. PV=计划完成工作的预算价值；EV=实际完成工作的预算价值（挣值）；AC=实际花费。**AC 是实际花费**。
3. SV=EV−PV（>0 提前）；CV=EV−AC（>0 节约）；SPI=EV/PV（>1 提前）；CPI=EV/AC（>1 节约）。
4. 典型 EAC=BAC/CPI（题干说趋势继续）；非典型 EAC=AC+(BAC−EV)（题干说剩余按计划）。
5. ETC=EAC−AC；VAC=BAC−EAC；TCPI=(BAC−EV)/(BAC−AC) 或 (BAC−EV)/(EAC−AC)。
6. 不包含。项目预算 = 成本基准 + 管理储备。
7. 应急储备应对已识别风险、在基准内、PM 管理；管理储备应对未识别风险、不在基准内、高层管理。
8. 一致性：预防成本、评估成本；非一致性：内部失败成本、外部失败成本。
9. −5% ~ +10%（最准确）。
</details>
