## 一、考试概况

### 三科结构与及格线

| 科目 | 题型 | 时长 | 满分 | 及格线 |
|---|---|---|---|---|
| **综合知识** | 75 道单选 | 150 分钟 | 75 | **45** |
| **案例分析** | 3 道大题（1 计算 + 2 问答） | 90 分钟 | 75 | **45** |
| **论文** | 2500 字，二选一 | 120 分钟 | 75 | **45** |

**关键规则（必须知道）**
> **三科必须在同一次考试中全部及格。单科成绩不保留。**
> 考试一年一次，通常在 **5 月下旬**。

**这意味着**：不能"今年过两科、明年补一科"。任何一科失手，三科都要重考。

### 各科目特点

| 科目 | 难度 | 提分方式 |
|---|---|---|
| 综合知识 | ★★ | 刷题 + 记忆，投入产出最高 |
| 案例分析 | ★★★ | 计算题必须练熟（不跳步），问答靠模板 |
| **论文** | ★★★★★ | **最难，且越来越反模板**，需真实项目素材 |

> 大多数人的失败点在**论文**，而不是选择题。复习时间分配要注意这一点。

## 五、必背清单

### 必背公式（9 个）

| # | 公式 | 用途 |
|---|---|---|
| 1 | **SV = EV − PV** | 进度偏差（>0 提前） |
| 2 | **CV = EV − AC** | 成本偏差（>0 节约） |
| 3 | **SPI = EV / PV** | 进度绩效（>1 提前） |
| 4 | **CPI = EV / AC** | 成本绩效（>1 节约） |
| 5 | **EAC = BAC / CPI**（典型） | 完工估算 |
| 6 | **EAC = AC + (BAC − EV)**（非典型） | 完工估算 |
| 7 | **三点估算 = (O + 4M + P) / 6** | 期望工期 |
| 8 | **沟通渠道 = n(n−1)/2** | 沟通复杂度 |
| 9 | **EMV = Σ(概率 × 金额)** | 决策树期望值 |

**补充**
```
ETC = EAC − AC
VAC = BAC − EAC（>0 有利）
TCPI = (BAC − EV) / (BAC − AC)
风险值 = 概率 × 影响
```

### 必背辨析（10 组）

| # | 对比项 | 区别 |
|---|---|---|
| 1 | **管理质量 vs 控制质量** | 过程 vs 结果 |
| 2 | **确认范围 vs 控制质量** | 客户验收 vs 内部检查 |
| 3 | **资源平衡 vs 资源平滑** | 改变工期 vs 不改变关键路径 |
| 4 | **赶工 vs 快速跟进** | 加资源（加成本）vs 并行（加风险） |
| 5 | **总价合同 vs 成本补偿合同** | 买方低风险/范围明确 vs 买方高风险/范围不确定 |
| 6 | **定性风险分析 vs 定量风险分析** | 排序 vs 数值化 |
| 7 | **质量保证 vs 质量控制** | 预防 vs 检查 |
| 8 | **项目集 vs 项目组合** | 依赖关系/收益 vs 战略优先级 |
| 9 | **应急储备 vs 管理储备** | 已识别风险/基准内 vs 未识别风险/基准外 |
| 10 | **事件管理 vs 问题管理** | 快速恢复 vs 根因消除 |

### 必背数字（5 组）

| 项目 | 数字 |
|---|---|
| 政府采购公告期 | **≥20 日** |
| 投标保证金 / 履约保证金 | **2%** / **10%** |
| 评标委员会 | **5 人以上单数**，专家 **≥2/3** |
| 控制图异常判定 | **连续 7 点**在中心线同侧 |
| 沟通、质量成本 | 沟通 **90%** 时间；预防成本最低 |

### 三个"唯一"（易考）

```
① 工作绩效数据 —— 只由「指导与管理项目工作」产出
② 核实的可交付成果 —— 只由「控制质量」产出
③ 验收的可交付成果 —— 只由「确认范围」产出
```

> 这三条几乎每年都考，是"过程链"的核心。

## 六、复习计划（25 周）

### 阶段划分

| 阶段 | 周次 | 内容 | 目标 |
|---|---|---|---|
| **打基础** | 1~10 周 | 十大知识领域逐个过 | 49 个过程能默写 |
| **补短板** | 11~14 周 | 第1~5章、第18章、第21章 | 记忆点全覆盖 |
| **练题** | 15~20 周 | 真题 + 案例计算 | 综合知识稳定 55+ |
| **攻论文** | 21~24 周 | 准备 3~5 个真实项目素材 | 能 2 小时内成文 |
| **冲刺** | 25 周 | 错题回顾 + 论文默写 | 保持手感 |

### 每周建议节奏

```
工作日：每天 1~1.5 小时（看 1 个知识领域 + 刷 20 题）
周末：4~6 小时（做 1 套真题 + 复盘错题 + 写 1 篇论文提纲）
```

### 关键提醒

> **论文要早准备。** 很多人拖到最后一个月，结果发现没有真实项目素材可用，只能编造——而第4版明确要求**反对虚构项目**，阅卷会扣分。
> **建议从第 15 周就开始积累素材**：记录你参与过的项目的规模、角色、关键事件、数据。

## 七、使用方法

### 三轮复习法

**第一轮（通读）**
```
按 01 → 17 顺序读，重点看：
- 「二、过程总表」——建立整体框架
- 「三、逐个重点」中的必背标记
跳过案例模板和论文要点（第一轮用不上）
```

**第二轮（自测）**
```
每章读完直接做「七、60 秒自测」，不看书
错的标记，回到「四、高频易错对照表」对照记忆
```

**第三轮（冲刺）**
```
只看两样：
- 各章的「高频易错对照表」
- 自己标记过的错题
```

### 案例题怎么用

```
每个文件的「五、案例题万能模板」是"问题清单 + 措施清单"。
答题时：
1. 先判断考的是哪个知识领域
2. 从模板里挑 3~4 条最贴合的问题
3. 措施与问题一一对应（不能只写问题不写措施）
```

### 论文怎么用

```
每个文件的「六、论文要点」列出了该领域的"加分项"。
准备素材时：
1. 选一个真实项目（做过的最好）
2. 按 10 个领域各准备 1~2 个具体事件
3. 要有数字（多少人、多少天、节省多少）
```

## 八、避坑提醒

### 复习误区

| ❌ 错误做法 | ✅ 正确做法 |
|---|---|
| 精读教材第1~5章（200+ 页） | 只看本资料第15章，覆盖 80% 考点 |
| 只刷题不背过程 | **49 个过程必须能默写**，这是骨架 |
| 论文拖到最后一个月 | 第 15 周就开始积累素材 |
| 平均用力各章节 | 十大领域占 53%，要重点投入 |
| 计算题心算 | **必须动笔写公式**，跳步会扣分 |
| 背教材原文 | 背**关键词和框架**，不背原文 |

### 考试注意事项

**综合知识**
```
75 题 / 150 分钟 = 每题 2 分钟
先做记忆题，最后做计算题（第21章）
不确定的先标记，不要死磕
```

**案例分析**
```
3 题 / 90 分钟 = 每题 30 分钟
第 1 题通常是计算（挣值/关键路径），必须写公式步骤
后 2 题是问答，按"问题+措施"结构作答
```

**论文**
```
2500 字 / 120 分钟
结构：摘要 250 + 背景 400 + 过程 1300 + 问题 350 + 总结 200
必须回应子题目（近年命题都附有 1~3 个子题目）
避免纯模板化表述，要有项目中的具体人物、数字、冲突
```
