## 二、政府采购法（最高频）

### 2.1 政府采购方式（必背）

| 方式 | 适用条件 | 关键数字 |
|---|---|---|
| **公开招标** | 主要方式，无特殊限制 | 公告期 **≥20 日** |
| **邀请招标** | 供应商少、特殊性 | 邀请 **≥3 家** |
| **竞争性谈判** | 技术复杂、时间紧急 | 谈判小组 **≥3 人**（单数） |
| **单一来源采购** | 唯一供应商 | 需**公示**，无异议 |
| **询价** | 货物规格标准统一、现货充足 | 询价小组 **≥3 人**（单数） |
| **竞争性磋商** | 技术复杂、需求无法确定 | — |

**必须记住的数字**
```
公开招标公告期限：不少于 20 日
邀请招标/竞争性谈判/询价的供应商：不少于 3 家
谈判小组、询价小组：3 人以上单数
评标委员会：5 人以上单数，技术经济专家不少于 2/3
中标公告期限：不少于 1 个工作日（有的表述为公告 1 个工作日）
采购合同签订：中标通知书发出之日起 30 日内
```

### 2.2 政府采购的关键期限（必背）

| 事项 | 期限 |
|---|---|
| **招标文件发售期** | 不少于 **5 个工作日** |
| **公开招标公告期** | 不少于 **20 日** |
| **中标通知书发出 → 签订合同** | **30 日**内 |
| **采购合同备案** | 签订之日起 **7 个工作日**内 |
| **供应商质疑** | 知道权益受损之日起 **7 个工作日**内提出 |
| **采购人答复质疑** | 收到质疑后 **7 个工作日**内 |
| **供应商投诉** | 答复期满后 **15 个工作日**内向财政部门投诉 |
| **财政部门处理投诉** | **30 个工作日**内作出决定 |

> 记忆锚点：**20 日公告、30 日签约、7 日质疑、15 日投诉、30 日处理**。

### 2.3 保证金与资金

```
投标保证金：不得超过采购项目预算金额的 2%
履约保证金：不得超过合同金额的 10%
采购资金支付：一般 30 日内支付
```

> **2% 是投标保证金，10% 是履约保证金。** 这两个最容易记混。

## 三、招标投标法

### 3.1 关键期限（必背）

| 事项 | 期限 |
|---|---|
| **招标文件发售期** | 不少于 **5 日** |
| **投标文件编制时间**（依法必须招标的项目） | 自招标文件发出至投标截止，不少于 **20 日** |
| **中标候选人公示** | 不少于 **3 日** |
| **中标通知书发出 → 订立合同** | **30 日**内 |
| **招标文件澄清/修改** | 投标截止时间 **15 日前**发出 |
| **合同备案** | 订立之日起 **15 日**内 |

### 3.2 关键数字

```
投标人少于 3 个的，招标人应当重新招标
评标委员会成员：5 人以上单数
技术、经济等方面的专家：不得少于成员总数的 2/3
中标人确定后，招标人应向中标人发出中标通知书
```

### 3.3 废标的情形（易考）

```
① 投标人少于 3 个
② 所有投标都不符合招标文件要求
③ 投标报价均超过预算且采购人无法支付
④ 出现影响采购公正的违法违规行为
⑤ 采购任务因重大变故被取消
```

## 四、合同法要点

### 4.1 合同的订立

**要约与承诺（必考辨析）**

| 概念 | 含义 | 特点 |
|---|---|---|
| **要约** | 希望与他人订立合同的意思表示 | 内容**具体确定**，表明经受要约人承诺即受约束 |
| **要约邀请** | 希望他人向自己发出要约 | **不受约束**（如招标公告、拍卖公告、商业广告） |
| **承诺** | 受要约人同意要约的意思表示 | 承诺生效时**合同成立** |

> **关键判断**：招标公告属于**要约邀请**；投标属于**要约**；中标通知书属于**承诺**。

**合同的成立与生效**
- **成立**：承诺生效时合同成立
- **生效**：依法成立的合同自成立时生效（附条件/附期限除外）

### 4.2 合同的履行与违约

**违约责任的形式**
```
继续履行、采取补救措施、赔偿损失、支付违约金、定金罚则
```

**违约金与定金（易考）**
- **定金**不得超过主合同标的额的 **20%**
- 定金与违约金**不能同时适用**（择一）
- 定金罚则：给付方违约→不得要求返还；收受方违约→双倍返还

**不可抗力**
- 因不可抗力不能履行合同的，**部分或全部免除责任**
- 关键：**及时通知**并提供证明

### 4.3 合同的解除

```
协商解除、约定解除、法定解除
法定解除情形：不可抗力致目的不能实现、预期违约、迟延履行经催告后仍不履行等
```

## 五、著作权法（软件相关）

### 5.1 软件著作权的归属（必考）

| 情形 | 归属 |
|---|---|
| **一般情况** | 开发者（自然人/法人） |
| **职务作品**（本职工作中开发） | **单位**（法人）享有 |
| **委托开发**（无约定时） | **受托方**（开发者） |
| **合作开发** | 合作开发者**共同享有** |

> **最常考**：委托开发**没有约定时，著作权归受托方（开发者）**，不是委托方！

### 5.2 软件著作权的保护期

```
自然人：作者终生 + 死亡后 50 年
法人/单位：首次发表后 50 年
（署名权等精神权利保护期不受限制）
```

### 5.3 软件著作权的权利内容

```
人身权：发表权、署名权、修改权
财产权：复制权、发行权、出租权、信息网络传播权、翻译权等
```

## 六、其他常用法规数字

### 6.1 劳动法相关（了解）

```
标准工时：每日不超过 8 小时，每周不超过 44 小时
加班：一般每日不超过 1 小时；特殊原因每日不超过 3 小时，每月不超过 36 小时
试用期：合同 3 个月~1 年 → 试用期不超过 1 个月
        1 年~3 年 → 不超过 2 个月
        3 年以上/无固定期限 → 不超过 6 个月
```

### 6.2 信息安全相关

```
网络安全等级保护：五个等级（一级最低，五级最高）
关键信息基础设施：等保三级以上
个人信息保护：处理个人信息应取得同意，最小必要原则
数据出境：需安全评估（重要数据、大量个人信息）
```

### 6.3 标准规范（了解）

| 标准类型 | 代号 | 说明 |
|---|---|---|
| **国家标准** | **GB**（强制）/ **GB/T**（推荐） | 全国范围统一 |
| **行业标准** | 如 **SJ**（电子）、**YD**（通信） | 特定行业 |
| **地方标准** | **DB** | 特定地区 |
| **企业标准** | **Q** | 企业内部 |
| **团体标准** | **T** | 社会团体 |

> 标准层级效力：**国标 > 行标 > 地标 > 企标**（但企业标准可以严于国标）。

### 6.4 软件工程相关标准（了解）

```
GB/T 8566  软件生存周期过程
GB/T 8567  计算机软件文档编制规范
GB/T 9385  计算机软件需求规格说明规范
GB/T 12504  计算机软件质量保证计划规范
```

## 七、高频易错对照表

| # | 陷阱 | 正解 |
|---|---|---|
| 1 | 投标保证金上限是 10% | 投标保证金 **2%**；履约保证金 10% |
| 2 | 公开招标公告期是 30 日 | **20 日**（政府采购与招投标都一样） |
| 3 | 质疑期是 15 日 | 质疑 **7 个工作日**；投诉 15 个工作日 |
| 4 | 中标后 15 日签合同 | **30 日**内签订合同 |
| 5 | 评标委员会 3 人以上 | **5 人以上单数**，专家不少于 2/3 |
| 6 | 谈判小组可以是 4 人 | 必须 **3 人以上单数** |
| 7 | 招标公告是要约 | 招标公告是**要约邀请**；投标是要约；中标通知书是承诺 |
| 8 | 委托开发著作权归委托方 | 无约定时归**受托方（开发者）** |
| 9 | 职务作品著作权归个人 | 归**单位** |
| 10 | 定金上限是 30% | **20%** |
| 11 | 定金和违约金可以同时主张 | **不能同时适用**，择一 |
| 12 | 软件著作权保护期是 30 年 | 自然人：终生+**50 年**；法人：发表后 **50 年** |
| 13 | 等保五级最低 | **一级最低，五级最高** |
| 14 | 投标人少于 5 个要重新招标 | **少于 3 个**就要重新招标 |
| 15 | 企业标准效力高于国标 | 国标效力**最高**（企业标准可以更严格） |
| 16 | 标准代号 GB 是推荐性 | **GB 是强制性**，GB/T 才是推荐性 |

## 八、背诵方法

**这章的正确背法**

```
① 先背"数字表"（20/30/7/15/30、2%/10%、3家/5人/2/3）
② 再背"归属规则"（职务作品、委托开发）
③ 最后看"要约/承诺"辨析（这个需要理解，但只有 3 个判断）
```

**数字记忆口诀**
```
招标公告 20 日，签合同 30 日
质疑 7 日，投诉 15 日，处理 30 日
投标保证金 2%，履约保证金 10%
供应商 3 家起，评标 5 人单数，专家 2/3
定金 20% 封顶
```

**最容易被忽略的**
> **政府采购与招标投标的期限不完全相同**：
> - 政府采购：招标文件发售 **5 个工作日**，质疑 **7 个工作日**
> - 招标投标法：招标文件发售 **5 日**，合同备案 **15 日**
>
> 考试时要注意题目问的是"政府采购"还是"招标投标"。

## 九、60 秒自测

1. 政府采购的六种方式？公开招标公告期多久？
2. 投标保证金与履约保证金的上限分别是多少？
3. 政府采购中，质疑、投诉、投诉处理的期限分别是多少？
4. 评标委员会的人数要求？专家占比？
5. 投标人少于几个需要重新招标？
6. 要约、要约邀请、承诺的区别？招标公告属于哪个？
7. 委托开发软件著作权归谁？职务作品归谁？
8. 软件著作权的保护期（自然人/法人）？
9. 定金的上限？定金与违约金能否同时适用？
10. 网络安全等级保护有几级？哪级最高？

<details>
<summary>答案</summary>

1. 公开招标、邀请招标、竞争性谈判、单一来源、询价、竞争性磋商；公告期不少于 20 日。
2. 投标保证金不超过预算 2%；履约保证金不超过合同金额 10%。
3. 质疑 7 个工作日；投诉 15 个工作日；财政部门 30 个工作日内处理。
4. 5 人以上单数，技术经济专家不少于 2/3。
5. 少于 3 个。
6. 要约是具体确定的意思表示（受约束）；要约邀请是希望他人向自己发要约（不受约束）；承诺是同意要约。招标公告属**要约邀请**。
7. 委托开发无约定时归**受托方**；职务作品归**单位**。
8. 自然人：终生加死亡后 50 年；法人：首次发表后 50 年。
9. 定金不超过标的额 20%；定金与违约金**不能同时适用**。
10. 五级；五级最高（一级最低）。
</details>
